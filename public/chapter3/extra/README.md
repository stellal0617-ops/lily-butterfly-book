# Chapter 3 additional garden assets

Put the 23 new **PNG** files directly in this folder (do not upload the ZIP itself). These are optional additional layered artworks for the Chapter 3 game. Do not rename existing images in the parent `public/chapter3/` directory.

Suggested workflow: Extract the `chapter3-new-game-elements.zip` file, open its `public/chapter3/extra` folder on your computer, then drag the PNG files into GitHub's **Add file → Upload files** screen here. Commit to `main`.

The code must be updated separately to use the new assets; merely adding files does not change the current garden game.
